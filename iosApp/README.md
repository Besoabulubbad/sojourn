# iosApp

The iOS application: a SwiftUI shell around the shared Compose UI.

- `iOSApp` starts Koin (`startKoinIos`) before the first view.
- `ContentView` hosts `MainViewController()` (in `app:shared`) edge to edge: Compose handles the safe areas (`SojournScaffold`).
- **Appearance:** `MainViewController` sets the window's interface style from the app's Appearance, so the status bar and system sheets match a Light or Dark choice.
- **Language:** `Info.plist` declares English and Arabic (`CFBundleLocalizations`), so Settings › Sojourn › Language offers them. The app reads that choice at launch through `AppleLanguages`, and an in-app choice writes the same key (ADR 0009).
- **Back:** Compose Multiplatform turns the start-edge swipe into back by default, and Navigation 3 handles it. The start edge is the right edge in Arabic.
- **Icon:** `Assets.xcassets/AppIcon.appiconset`, light and dark, generated by `tooling/scripts/make_brand.py`.

Build it with Xcode (`iosApp.xcodeproj`), or check the shared framework with `./gradlew :app:shared:linkDebugFrameworkIosSimulatorArm64`.
