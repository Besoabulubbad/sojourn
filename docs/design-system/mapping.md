# Design system → code

The design system was authored outside this repository as a Design System artifact and is adapted here under the Sojourn name. This page is the contract between its cards and our Kotlin: how tokens become objects, how each component card becomes a `Sojourn*` composable, and where each screen lives. When the design system changes, this page changes in the same PR as the code.

## Tokens → Kotlin

Generated by the `sojourn.tokens` convention plugin from `design/tokens.json` into `core:designsystem` (`build/generated/tokens/`). Never edited by hand.

| tokens.json family | Generated object | Shape | Example use |
|---|---|---|---|
| `color.tokens` (light/dark) | `SojournColors` + `lightSojournColors()`, `darkSojournColors()` | `@Immutable class SojournColors(val bg: Color, val surface: Color, val ink: Color, … val mapRoad: Color, val photoAccent: Color)` | `SojournTheme.colors.brand` |
| `type.groups[].styles[]` | `SojournType` | `@Immutable class SojournType(val display: TextStyle, val titleLg: TextStyle, … val caption: TextStyle)` built by `sojournType(display, text)` from `SojournFonts.alexandria()` / `readexPro()`; tabular figures on every style | `SojournTheme.type.price` |
| `spacing.tokens` | `SojournSpacing` | `object SojournSpacing { val space1 = 4.dp … val space10 = 40.dp }` | `SojournSpacing.space4` |
| `radius.tokens` | `SojournShapes` | `object SojournShapes { val xs = RoundedCornerShape(6.dp) … val full = RoundedCornerShape(999.dp); val sheetTop = RoundedCornerShape(topStart = 28.dp, topEnd = 28.dp) }` | `SojournShapes.lg` |
| `shadow.tokens` (light/dark) | `SojournElevation` | `@Immutable class SojournElevation(val level1: SojournShadow, level2, level3)` with `SojournShadow(elevation: Dp, color: Color)`: elevation is half the CSS blur, the tint is the shadow colour | `SojournTheme.elevation.level2.elevation` |
| `size.tokens` | `SojournSizes` | `object SojournSizes { val touchMin = 48.dp; val icon = 24.dp; val iconSm = 20.dp; val barTop = 56.dp; val barBottom = 64.dp; val bookingBar = 72.dp }` | `SojournSizes.touchMin` |
| `duration.tokens` + `easing.tokens` | `SojournMotion` | generated: `object SojournMotion { const val instant = 100 … const val slower = 500; val standard = CubicBezierEasing(0.2f, 0f, 0f, 1f); val emphasized; val exit }`; hand-written extensions: `settleSpring()` (400, 0.8), `popSpring()` (400, 0.6), `exitDuration()`, `enter()` / `exit()` / `move()` honouring `LocalReduceMotion` | `SojournMotion.enter(SojournMotion.slow)` |

Token names map to Kotlin by kebab → lowerCamel (`surface-sunken` → `surfaceSunken`, `on-brand` → `onBrand`, `title-lg` → `titleLg`). A test asserts the generated object has exactly one property per token so a renamed or removed token fails the build rather than silently falling back.

`SojournTheme` exposes `colors`, `type`, `elevation` and `isDark`; `SojournSpacing`, `SojournShapes`, `SojournSizes`, `SojournMotion` are objects because they do not vary by theme.

## Components → composables

All in `core:designsystem`, package `com.abulubad.sojourn.core.designsystem.components`. Each has KDoc, previews for every state in the 4-variant matrix, a screenshot test, and a README section mirroring the card's guideline. "Card" is the design system's `api/components/<Comp>.md`.

| Card | Group | Composable(s) | Notes from the card we encode in the API |
|---|---|---|---|
| Button | Actions | `SojournButton(text, onClick, modifier, variant: Primary \| Secondary \| Ghost \| Danger, leadingIcon?, loading, enabled)` ✅ | one primary per screen (review); labels wrap, never truncate; loading keeps label and width and blocks a second tap; press scale 0.98 + 8 % darken over `SojournMotion.instant`; 2 dp focus ring |
| Chip | Actions | `SojournChip(label, selected, onClick, modifier, icon?)` / `SojournFactChip(label, modifier, icon?)` ✅ | selected changes fill **and** weight (C-04), read as "selected"; 40 dp visual, 48 dp target; fact chips are read-only `brandTint` |
| IconButton | Actions | `SojournIconButton(icon, contentDescription, onClick, modifier, variant: Plain \| Outline \| Floating, tint: Default \| Saved, badge?, enabled)` ✅ | `contentDescription` required (C-05); 48 dp target always; floating carries its own `surface` disc for photos and the map; badge text is `label-sm` (the card's 11 px is below the brand book's minimum) |
| SearchBar | Inputs | `SojournSearchBar(summary: SearchSummary?, compact: Boolean, onClick)` | the single entry to search; container-transform source |
| DateRangePicker | Inputs | `SojournDateRangePicker(state, onRangeChange, unavailable: Set<LocalDate>)` | month grid; first day of week from `AppLocale` (L-04); range tint sweep `SojournMotion.fast` |
| RangeSlider | Inputs | `SojournPriceRange(range, bounds, histogram, basis: PriceBasis, onChange)` | `basis` required (P-04); two editable fields; thumbs `SojournElevation.level2` |
| SegmentedControl | Inputs | `SojournSegmentedControl(options: List<Segment>, selectedIndex, onSelect)` | 2–5 options; thumb `SojournShapes.sm`, `SojournElevation.level1` |
| Stepper | Inputs | `SojournStepper(value, range, onChange, label, haptics = true)` | light tick on change |
| TopBar | Navigation | `SojournTopBar(title?, navigationIcon?, actions, style: Solid \| OverPhoto, scrollState?)` | owns status inset (I-01); over photos uses `scrimTop` and floating buttons (I-02); fill tied to scroll over 48dp |
| BottomNav | Navigation | `SojournBottomNav(tabs: List<Tab>, selected, onSelect)` | four destinations; owns bottom inset; active pill `brandTint` |
| Sheet | Navigation | `SojournSheet(state: SheetState, detents: Peek \| Half \| Full, onDismiss, content)` | drag handle + close button on Android; owns bottom inset; `SojournShapes.sheetTop`; enter `slow`, scrim `base` |
| ViewToggle | Navigation | `SojournViewToggle(mode: List \| Map, onToggle)` / `SojournSearchAreaPill(onClick)` | floating pill; `SojournElevation.level3` |
| CityCard | Listing | `SojournCityCard(city, fromPrice: PriceDisplay.From, count, onClick)` | monthly *from* prices |
| Gallery | Listing | `SojournGallery(photos, index, onIndexChange, onOpen)` / `SojournFullScreenGallery` | placeholder / loaded / failed-with-retry per slot; counter in bidi isolate (S-04) |
| KeyFacts | Listing | `SojournKeyFacts(facts: StayFacts)` | four counts, one icon each; "Studio" never "0 bedrooms" (N-01) |
| PolicyRow | Listing | `SojournPolicyRow(policy: Policy)` | policy carries its number (N-03) — `Policy` type requires it |
| Price | Listing | `SojournPrice(price: PriceDisplay, modifier, size: SojournPriceSize = Card \| Compact)` ✅ | **the only price renderer** (P-01); `Total` leads with the stay total over the all-in nightly average; `From` says "from … a month/night" over what it excludes (P-03) |
| PricePin | Listing | `SojournPricePin(display, selected, seen, onClick)` / `SojournClusterPin(count)` | select: scale 1.12 + invert, `SojournMotion.fast` |
| Rating | Listing | `SojournRating(rating: Rating?, modifier, showCount = true)` ✅ | renders nothing under 3 reviews or when missing (N-04), tested on the semantics tree; read aloud as one phrase "Rated 4.8 out of 5, 32 reviews" |
| StayCard | Listing | `SojournStayCard(stay: StayCardModel, price: PriceDisplay, saved, onSave, onOpen)` | 16:10 swipeable photos, area, rating, facts, price, heart; no shadow in lists |
| BookingBar | Booking | `SojournBookingBar(price: PriceDisplay, action: BookingAction, onAction)` | docked, opaque, owns inset (I-03); never disabled |
| PriceBreakdown | Booking | `SojournPriceBreakdown(breakdown: PriceBreakdown)` | lines sum to total — `PriceBreakdown` validates on construction (P-05) |
| EmptyState | Feedback | `SojournEmptyState(icon, title, body, modifier, action: SojournEmptyStateAction?)` ✅ | title says what happened, body what to do, at most one action that changes the outcome; 64 dp `brandTint` icon disc; title is a heading |
| Skeleton | Feedback | `SojournSkeleton(modifier, shape)` / `SojournStayCardSkeleton(modifier)` ✅ | 1.4 s `hairline` pulse that stops under reduce motion; hidden from screen readers, the container announces "Loading" |
| Snackbar | Feedback | `SojournSnackbar(message, modifier, actionLabel?, onAction)` + `SojournSnackbarHost(state)` with `SojournSnackbarHostState.show()`; `SojournOfflineBanner(message, modifier, actionLabel?, onAction)` ✅ | 5 s on screen, announced politely, undo instead of confirmation dialogs; the offline banner uses `dangerTint` and pushes content down |
| Icons | Foundations | `SojournIcon` sealed class (58 icons: `SojournIcon.Back`, `.Search`, `.Saved`, … with `autoMirror`) + `SojournIcon(icon, contentDescription, modifier, tint, size)` | Lucide 24dp / 1.75 stroke as vector resources (`lucide-static` 1.73.0); only Back, Forward and the start/end chevrons mirror, inside the composable (L-05) |
| Motion | Foundations | `SojournMotion` + `SojournTransitions` (container transform, step slide, sheet enter, pin select, save pop, price swap) | ceiling `slower` (M-02); `reduced` → 150ms fade (M-03); direction from `LayoutDirection` (M-04) |

Shared type additions required by the cards live in `core:model`: `PriceDisplay`, `PriceBasis`, `PriceBreakdown`, `StayFacts`, `Policy`, `SearchSummary`, `StayLength`.

## Brand book rules we encode

- **Voice and glossary.** One term per concept per language: `stay`, `saved`, `bookings`, `filters`, `wifi`, `washer`, `workspace`, `studio`, `lift`, `refundable_deposit`, `reserve` are the resource key stems; Arabic values are the glossary's. Sentence case; buttons are verb + object.
- **Numbers, dates, money.** Western digits in both languages; money `£1,383` (en) / `1,383 £` (ar) inside a bidi isolate; date ranges with an en dash; six Arabic plural forms. All through `SojournFormatter`.
- **Colour.** Screens on `bg`, cards on `surface`, recessed on `surfaceSunken`; `brand` = primary action; `accent` = long-stay badge only; `save` = heart only; discounts in `brandInk` with a minus sign; dividers `hairline`; tappable outlines `borderControl`; `on-*` tokens on fills; focus ring 2dp `focus` with 2dp offset.
- **Type.** Alexandria for display/titles/price; Readex Pro for text; 12sp minimum; no Arabic italics or letter spacing; tabular figures; scales to 200% without clipping.
- **Layout.** Margin `space4`, section gap `space6`, in-card `space3`; 48dp targets; start/end only; edge-to-edge with bars owning insets; corners `lg` photos/cards, `md` buttons/fields, `full` chips/pins/search, `xl` sheet tops; elevation rare.
- **Imagery and maps.** 16:10 in lists, full-bleed on Details; every slot has placeholder/loaded/failed; map styled from `map*` tokens and follows the app theme; a stay's position is an area before booking.
- **Platform differences.** Back: system/predictive on Android, edge swipe on iOS. Sheets: handle + close on Android. Haptics: light tick / light impact. Payment: Google Pay / Apple Pay sheet first. Share: platform sheet. Formats: from `AppLocale` on both.

## What the design system leaves open (and our choice)

| Open | Our choice |
|---|---|
| Official logo and brand files | none existed; a wordmark and app icon are drawn from the tokens in the showcase workstream |
| Photography | placeholder art using `photo*` tokens in previews; bundled sample photos for the demo |
| Sign-up/login, card entry, reviews list | out of scope (see plan) |
| Fonts as files | Alexandria and Readex Pro bundled as Compose font resources in `core:designsystem` |
