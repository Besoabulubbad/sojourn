# Brand

The Sojourn mark is a doorway arch with a lamp inside it: a home base, wherever and for however long. It is drawn only from design tokens, `brand` for the ground, `bg` for the arch and `accent` for the lamp, with the dark theme's values for the dark variant. The wordmark is "Sojourn" set in Alexandria SemiBold in `brand-ink`, outlined to paths so it renders without the font.

| File | Use |
|---|---|
| `sojourn-mark.svg`, `sojourn-mark-dark.svg` | App icon artwork on Android's 108-unit adaptive grid; the arch and lamp sit inside the 66-unit safe zone |
| `sojourn-wordmark.svg`, `sojourn-wordmark-dark.svg` | The name alone |
| `sojourn-lockup.svg`, `sojourn-lockup-dark.svg` | Mark and wordmark together, used in the README header |

Everything here, the Android adaptive icon (foreground, background colour, monochrome for themed icons, PNG fallbacks for API 24–25) and the iOS light and dark app icons are generated by one script:

```bash
python3 -I tooling/scripts/make_brand.py   # needs fontTools (pip) and rsvg-convert (Homebrew librsvg)
```

Change a token in `design/tokens.json`, re-run the script, and the brand follows. Do not edit the outputs by hand.
